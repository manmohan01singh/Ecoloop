## ⚡ Quick Actions

### User Management:
1. Go to **Users** tab
2. Search for user
3. Change role via dropdown
4. Update verification status
5. Changes save automatically

### Verify Provider:
1. Go to **Providers** tab
2. Review provider details
3. Click **Verify** or **Reject**
4. Provider status updated

### Verify Location:
1. Go to **Locations** tab
2. Review location details
3. Click **Verify** or **Reject**
4. Location status updated

### Handle Report:
1. Go to **Reports** tab
2. Review report details
3. Select status (under_review, verified, resolved, rejected)
4. Report updated

### View User Contributions:
1. Go to **Contributions** tab
2. Find user/organization
3. Click **View** button
4. See detailed breakdown:
   - Posts, Devices, Listings
   - Waste Deposits, Repair Requests
   - Recent EcoKarma activity

## 📈 Platform Health Indicators

### Check System Health:
1. Go to **Overview** tab
2. Review key metrics:
   - Total users (growth)
   - Active content (posts, listings)
   - Pending items (reports, verifications)
   - Engagement (karma, reviews)

### Monitor Growth:
1. Go to **Analytics** tab
2. View daily trends:
   - User registrations
   - Content creation
   - Material listings
   - Event hosting

### Identify Issues:
1. High pending reports → Check **Reports** tab
2. High pending providers → Check **Providers** tab
3. High pending locations → Check **Locations** tab
4. Low user growth → Check **Analytics** tab
