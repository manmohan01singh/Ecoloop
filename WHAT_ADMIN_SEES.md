## 🎨 Color Legend

```
Status Colors:
🟢 Green  → Active, Verified, Completed, Listed
🔵 Blue   → Pending, Upcoming, Ongoing
🟡 Yellow → Under Review, Requested, Accepted
🟣 Purple → In Progress, Processing
🔴 Red    → Rejected, Cancelled, Flagged
⚫ Gray   → Inactive, Unverified, Closed

Dashboard Colors:
🔵 Blue    → User-related data
🟣 Purple  → Content-related data
🟢 Green   → Business-related data
🔵 Indigo  → Organization-related data
🟠 Orange  → Repair-related data
🟦 Teal    → Recycler-related data
🔴 Red     → Moderation-related data
🌸 Pink    → Engagement-related data
```
